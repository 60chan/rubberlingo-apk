# Rubberlingo Android 설치 파일

고무 컴파운드 연구팀 학습 앱 Rubberlingo의 Android 설치 파일(APK)을 올려 두는 곳입니다. 앱 소스는 여기 없습니다.

- **최신 버전 받기**: https://github.com/60chan/rubberlingo-apk/releases/latest/download/rubberlingo.apk
- 다운로드가 100%가 돼도 설치 화면이 저절로 뜨지 않으면 알림을 누르거나 '내 파일 → 다운로드'에서 `rubberlingo.apk`를 누르세요. "이 출처 허용"을 켜고 설치합니다 (Play 프로텍트 경고는 '무시하고 설치').
- 설치한 뒤에는 앱의 업데이트 공지나 설정의 "업데이트"를 누르면 이 주소에서 새 버전을 받습니다.
- iPhone은 Safari로 https://rubberlingo.expo.app 을 열고 공유 → 홈 화면에 추가.
